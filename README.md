# Website Optimization: Performance, SEO, and Accessibility

This project involved optimizing an existing Bootstrap and jQuery-based website. 
The main focus was on debugging, improving website performance, enhancing SEO (including local and social media SEO), and ensuring basic accessibility.

## Objectives
- Debug existing JavaScript/jQuery functionalities.
- Optimize website performance.
- Improve SEO, including local referencing and social media optimization.
- Enhance basic website accessibility.

## My Contribution
- Debugged JavaScript/jQuery errors affecting the image gallery functionality.
- Improved website performance by reducing image sizes and load times.
- Implemented SEO improvements: meta tags, local SEO enhancements, and social media metadata.
- Improved basic website accessibility (alt texts, semantic HTML).

## Technologies Used
- HTML / CSS (Bootstrap)
- JavaScript / jQuery (debugging existing code)
- Google Lighthouse (Performance and SEO audits)

## What I Learned
- Debugging existing JavaScript and jQuery code.
- Fundamental website performance optimization techniques (image compression).
- Implementing SEO best practices, including local referencing and social media metadata.
- Basics of improving website accessibility.
